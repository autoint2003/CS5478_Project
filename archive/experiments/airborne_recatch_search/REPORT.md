# 空中拦截 recatch 搜索

这次搜索没有找到可以加入 SFT 的合法空中 recatch。8 个 TRAIN 初始条件、128 条真实 MuJoCo 分支里，没有任何一条在落桌前重新形成双侧夹持，因此也没有进入 K48 量化或 `SUCCESS_12S`。

这不是“所有 IC 都不可恢复”的证明。它是这一组速度受限的拦截候选，在实测的 0.13 s 左右落桌窗口里没有捕获圆柱。

## 1. 修改的文件

新增，不覆盖旧的 `chase_lost`、snapshot、manifest 或 checkpoint：

- `training/probe_airborne_capability.py`：测量手的真实速度和夹爪开合时间。
- `training/airborne_intercept_recatch.py`：`InterceptPolicy`、`rollout`、`candidate_grid`、`search_ic`。
- 结果目录 `results/diagnostics/airborne_recatch_search/`。

每个候选都从原始 snapshot 调用 `restore_capture`，再只通过 `step_legal` 发送 `recovery7d_airborne_v3` 动作。没有改 `qpos`、`qvel`、质量、摩擦、重力或桌面，也没有清除 `TABLE_DROP`。

## 2. 实测约束

测量对象是 `ball_train_v2_0051` 的恢复起点，跟踪器就是 `step_legal` 使用的 Cartesian PD（`kp_pos=1400`，`kd_pos=80`）。`p_des` 每个 20 ms 控制步被重置为当前手的位置，所以指令速度不是手的瞬时速度。

| 量 | 实测 |
| --- | --- |
| 控制步 / 物理步 | 20 ms = 10 × 2 ms；恢复上限 4 s = 200 步 |
| 手坐标系 | x ≈ 世界 +Y，y ≈ 世界 +X（张开方向），z ≈ 世界 −Z（指尖朝下） |
| 指令 +1 的手系 x / y | 1.0 m/s；实际中位速度 0.77 / 0.55 m/s |
| 指令 −1 的手系 z（向上） | 1.0 m/s；实际中位 0.64 m/s |
| 指令 +1 的手系 z（向下） | 3.8 m/s；前 0.5 s 的中位速度只有 0.25 m/s，不能当作可用拦截速度 |
| 单独的腕部指令 | 4 rad/s 的指令会带出约 0.16 m 的平移，搜索里腕部速度限制在 0.40 rad/s |
| 夹爪 | 关节 0–0.04 m；从 0.013 m 张到 0.030 m 需要 0.08 s；闭合到 0.005 m 需要 0.04 s |
| 力矩 | 动作 −1 对应张开 +2 N·m，动作 +1 对应夹紧 −18 N·m；执行器范围 ±50 N·m |
| 圆柱 | 质量 0.20 kg，半径 0.018 m，半高 0.030 m，摩擦 `1.0 0.005 0.0001` |
| 桌面 | 顶面 z = 0.40 m，半尺寸 0.12 m，中心 (0.50, 0.0) |
| 指尖 | 左右指在手系 y = ±0.013 m、z = 0.058 m；稳定夹持时圆柱质心约在手系 z = 0.10 m |
| K48 | 47 个运动码字，residual 每个分量 ±0.25。没有放宽 |

`0051` 在 t = 3.28 s 时仍有接触（nL = 2，nR = 1），但圆柱质心已经沿手系 x 偏出 25 mm，角速度 2.40 rad/s。按当时的高度和速度，若立刻脱手，最低点到达桌面大约只要 0.138 s。张开夹爪就要 0.08 s。后续 IC 的预测落桌时间是 0.128–0.145 s。

搜索因此把相对修正限制在 0.03–0.08 m/s，并让手速跟随圆柱速度。不受限制的位置增益会把 25 mm 误差放大成 0.7 m/s 的横移，把圆柱推出桌面；那一版没有保留。

## 3. 搜索算法

控制器按接触状态切换，不是一条固定到底的 PD：

- 双侧接触或圆柱已在两指之间：夹爪保持当前候选的闭合指令，手速度等于圆柱速度加上不超过 `held_speed` 的位置修正。
- 双侧接触连续消失 40 ms：记为一次空中失握。夹爪张开，瞄准 `p + vτ + ½gτ²` 处的夹持点。脱离夹持后，目标的水平位置限制在起始手位置的 6 cm 内，避免追出桌面。
- 失握之后重新出现双侧接触、圆柱位于指间、并保持 3 个控制步：记为捕获，再把夹持点缓速送回名义手位置。
- 捕获后调用现有 `finish_recovery`。连续成功且确实发生过 40 ms 失握时，才做 K48 `legalize`，并用 `legal_verify` 从原始 IC 重放量化动作。

候选是同一个 snapshot 上的 16 个分支：4 个不主动张开的闭合跟随（闭合指令 1.0 或 0.2，修正速度 0.03 或 0.06 m/s），以及 12 个拦截（预测时间 0.04 / 0.08 / 0.12 s，修正速度 0.04 或 0.08 m/s，腕部对齐开或关）。若出现捕获，再在该参数附近做最多 4 个细化分支。每个 IC 上限 40 个候选或 250000 个物理步。

预测只用来生成目标点。接受与否只看 MuJoCo rollout。

## 4. 预算

8 个 IC，每个 16 个候选，共 128 次 rollout。没有候选进入细化。物理步合计 68482，墙钟时间 39.9 s。原始计数在 `raw/summary.json` 和 `raw/records.json`。

## 6. 关键轨迹

轨迹在 `trajectories/*.json`，每 20 ms 一条，含接触数、夹爪开度、手和圆柱的位置与速度。

`ball_train_v2_0051`，闭合跟随，修正上限 0.03 m/s：

- t = 3.28 s：nL/nR = 2/1，z = 0.518 m，开度 0.013 m，圆柱速度 (−0.018, 0.127, 0.077) m/s，质心在手系 (0.025, 0.000, 0.101) m。
- t = 3.50 s：双侧接触消失，开度已经收到 −0.004 m（越过关节 0 点），z = 0.507 m，竖直速度 −0.467 m/s。圆柱仍在指尖高度附近，但沿手系 x 偏出 31 mm，两指已经合上。
- t = 3.60 s：`TABLE_DROP` latch，z = 0.423 m，速度 (−0.069, 0.644, −0.383) m/s。从确认失握到落桌约 0.10 s。

`ball_train_v2_0226` 在 t = 3.26 s 失握，t = 3.38 s latch。角速度 6.92 rad/s，水平速度在失握时达到 0.46 m/s。

`k48r_train_00135` 角速度只有 0.16 rad/s，仍然在 t = 3.54 s 失握、t = 3.64 s latch。闭合后的指间距小于圆柱直径 36 mm，圆柱停在指尖外侧。

`ball_train_v2_0251` 直到 t = 4.98 s 才双侧脱开，此时 z = 0.433 m、水平速度 0.45 m/s，随后掉到 z = 0.299 m 且没有桌面 latch。它离开了 0.24 m 宽的桌面，现有的 z < 0.30 m 规则先终止了分支。

## 7. 连续成功和 K48

两者都是 0。量化器没有被放宽，也没有被用来把失败轨迹改成成功。

## 8. TABLE_DROP

6 个发生明确落桌的 IC 都由 latch 终止，失握到 latch 约 0.08–0.12 s，不是原来的 1 s 无接触计时。latch 在分支内没有被清除。`0251` 没有 latch，是因为它掉到了桌面范围之外，先触发了 z < 0.30 m。`00150` 和 `0098` 在恢复阶段没有 latch；失败发生在 handoff 之后的 nominal 阶段，原因是 `DROP_AFTER_HANDOFF`。

## 9. 独立验证

`finish_recovery` 只在恢复阶段结束时仍有双侧接触的 `00150` 和 `0098` 上运行，结果都是 `DROP_AFTER_HANDOFF`。其余分支在恢复阶段已经失败，没有 nominal 成功可以重放。`legal_verify` 没有接受任何量化动作。

## 11. 还没有解决的限制

- 这些冲击状态留给空中再抓取的时间约 0.13 s。夹爪从当前 13 mm 张到能让 36 mm 直径圆柱重新进入，需要约 0.08 s。闭合本身只要 0.04 s，但此时指缝已经小于圆柱直径。
- 手的向下速度建立很慢。3.8 m/s 的向下指令在 0.5 s 内的中位实际速度只有 0.25 m/s，来不及跟着自由落体下降。
- 圆柱质心沿指长方向偏出 15–25 mm，而指垫在这个方向上很短。全速夹紧会把圆柱挤到指尖外面，而不是夹进两指之间。
- 腕部对齐会带来明显平移，所以大部分候选没有依赖大幅度转腕。高速自旋（`0226` 为 6.92 rad/s）在 0.1 s 内转过约 40°，固定指向对不准新的夹持面。
- 两个把接触维持满 4 s 的 IC 交给现有 nominal 控制器后仍然掉落。空中再抓取即使捕获，还要能把姿态交回去。

要提高捕获率，需要在不放宽动作空间和 `TABLE_DROP` 的前提下，找到一种不会把偏心圆柱挤出去的闭合过程，并在 0.1 s 内把指缝重新张开到 36 mm 以上。这次 16 个候选没有做到。
